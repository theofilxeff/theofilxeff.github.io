Erdős problem Full proof

Erdős 131

Let F(N) be the largest size of a set A ⊆ {1, …, N} in which no element divides the sum of any nonempty subset of the remaining elements. Erdős, Lev, Rauzy, Sándor and Sárközy proved F(N) = O(N1/2), and constructions of Erdős give F(N) ≫ N1/5. We prove the matching upper bound: F(N) = N1/5+o(1), resolving the problem. The proof has been formally verified in Lean 4.

Erdős 959

Partial proof because it does not solve the Erdős problem. For a finite set A ⊂ ℝ2, let fA(r) be the number of unordered pairs at distance r, and let G(n) be the maximum gap between the two largest values of fA over all n-point sets. We prove that there is an effectively computable constant c > 0 such that G(n) ≥ n1+c for every sufficiently large integer n.
